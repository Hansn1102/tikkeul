# 티끌 · 개인 재정 트래커

수입과 지출을 기록하고 순수익 · 예산 · 목돈 목표를 한 화면에서 보는 데스크톱 우선 웹앱.
빌드 도구 없는 정적 페이지(HTML + CSS + vanilla JS)이며 모든 데이터는 브라우저 localStorage에만 저장됩니다.

## 기능
- **대시보드** 현재 잔액, 월 수입/지출/순수익, 6개월 현금 흐름, 예산 소진과 하루 사용 가능액
- **거래 내역** 월·구분·분류·검색 필터, 인라인 수정/삭제, CSV 내보내기
- **분석** 하루 평균 지출, 저축률, 최다 지출일, 고정비 비중, 월별 추이(6/12개월), 카테고리 랭킹, 일별 지출
- **목돈 목표** 목표 금액과 기한으로 매달 필요 저축액 계산, 목표별 적립 기록
- **예산·설정** 월 예산, 고정비, 시작 잔액, JSON 백업/복원, 전체 삭제
- 단축키 `N` 새 거래 · `/` 검색 · `1~5` 화면 이동 · `Esc` 닫기
- 시스템 라이트/다크 테마 자동 대응, PWA 오프라인 지원

## 데이터 안전장치
- **날짜별 스냅샷** 저장할 때마다 하루 한 개씩 자동 보관(최근 7개), 설정 화면에서 되돌리기
- **로컬 파일 자동 백업** 파일을 한 번 지정하면 기록할 때마다 그 파일에도 자동 저장(File System Access)
- **복구 배너** 기록이 비었는데 스냅샷·백업에 거래가 남아 있으면 상단에서 복구 제안

## 기기 간 동기화 (선택)
폰과 데스크톱이 같은 기록을 보게 하려면 Supabase 무료 프로젝트 하나만 있으면 됩니다.

1. supabase.com 에서 무료 프로젝트 생성
2. SQL Editor 에 저장소의 [`supabase.sql`](./supabase.sql) 붙여넣고 Run
3. Project Settings → API 에서 **Project URL**과 **anon public key** 복사
4. 앱 → 예산·설정 → 기기 간 동기화 → 연결에 붙여넣기
5. 다른 기기에서는 **설정 복사**로 얻은 한 줄만 붙여넣으면 연결됨

동기화 코드(48자 랜덤)를 아는 기기끼리만 기록이 오갑니다. 테이블 직접 접근은 막혀 있고
`get_doc`, `put_doc` 함수로 코드가 정확히 일치할 때만 읽고 씁니다. 거래·목표는 id 기준으로
합쳐지며, 삭제한 거래는 삭제 기록이 남아 다른 기기에서 되살아나지 않습니다.

## 로컬 실행
```bash
python3 -m http.server 8000
```

## 데이터
브라우저 저장소(localStorage `tikkeul.v2`)에만 남고 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 함께 사라지므로 설정 화면에서 JSON 백업을 주기적으로 내려받으세요.
